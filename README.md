# prompt1-shell-argentina

Respaldo con historial de versiones del reporte de visibilidad en IA de **Shell Argentina** (cliente de Prompt1).

- `shell-argentina.html` — el HTML completo del reporte (el mismo que se publica como artifact y se embebe en `prompt1.ai/clientes` vía iframe).
- Cada commit representa una versión aprobada/publicada, con fecha clara en el mensaje de commit — así siempre se puede volver a un punto exacto en el tiempo.

Este repositorio es privado y es solo un respaldo técnico: no reemplaza el flujo de trabajo (local → aprobar → publicar en Wix), solo guarda una copia con historial de cada versión confirmada.
